# GigaDictate 🎙️⚡

Высокоскоростное приложение для голосового набора текста (Speech-to-Text) на macOS, работающее **полностью локально** на моделях **[GigaAM-v3](https://github.com/salute-developers/GigaAM)** от Salute Developers.

Приложение работает в фоновом режиме в строке меню (Menu Bar), вызывается назначенной горячей клавишей и **автоматически вставляет распознанный текст прямо под курсор** в любую активную программу (Telegram, VS Code, браузер, заметочник, мессенджер и т.д.).

---

## Особенности

- 🚀 **Сверхбыстрый инференс на Apple Silicon (M1/M2/M3/M4)**: 
  - Задействует аппаратное ускорение **MPS (Metal Performance Shaders)** GPU Mac.
  - Скорость распознавания: **~0.18 секунды** на 10-секундную фразу (в 50+ раз быстрее реального времени!).
  - Аудиопоток обрабатывается напрямую в оперативной памяти (без лишних записей на диск и вызовов внешних утилит).
- ✍️ **Пунктуация и заглавные буквы из коробки**:
  - По умолчанию используется модель `v3_e2e_ctc`, которая сразу расставляет точки, запятые, знаки вопроса и заглавные буквы.
  - Также доступны `v3_e2e_rnnt`, `v3_ctc`, `v3_rnnt`.
- ⌨️ **Любая горячая клавиша и 2 режима работы**:
  - **Push-to-Talk** (по умолчанию): зажмите клавишу (например, `Правый Shift`), говорите, отпустите — текст мгновенно появляется под курсором.
  - **Переключение (Toggle)**: нажмите один раз для старта записи, нажмите второй раз для остановки и вставки.
  - Настраивается прямо из меню (пресеты: `Правый Shift`, `Правый Option`, `F8`, `Ctrl+Пробел` или **любая произвольная клавиша / сочетание** через диалоговое окно).
- 📍 **Вставка под курсор**:
  - Автоматическая вставка через имитацию `Cmd+V`.
  - Текст также сохраняется в буфере обмена (даже если разрешения временно не выданы, текст не пропадет).
- 🔈 **Звуковая обратная связь**:
  - Приятные тихие системные звуки macOS (`Tink` при старте, `Pop` при остановке, `Hero` при успешной вставке), позволяющие диктовать не глядя на экран.
- 📜 **История распознаваний**:
  - Меню хранит последние распознанные реплики с возможностью скопировать любую в один клик.

## Быстрый запуск

### Вариант 1. Через скрипт запуска
```bash
./run.sh
```

### Вариант 2. Запуск приложения macOS
Вы можете запускать готовый бандл **`GigaDictate.app`**:
```bash
open GigaDictate.app
```
*(Или перетащите `GigaDictate.app` в папку `/Applications`)*.

## Настройка разрешений macOS 🛡️

Для полноценной работы приложению на Mac требуются 2 стандартных разрешения:

1. **Микрофон (Microphone)**:
   - При первом запуске и записи macOS покажет стандартный системный запрос на доступ к микрофону. Нажмите «Разрешить».
2. **Универсальный доступ (Accessibility)**:
   - Требуется операционной системой macOS для того, чтобы приложение могло эмулировать нажатие `Cmd+V` и вставлять текст туда, где находится курсор.
   - Откройте **Системные настройки → Конфиденциальность и безопасность → Универсальный доступ** (System Settings → Privacy & Security → Accessibility).
   - Включите переключатель для `GigaDictate` (или для вашего Терминала, если запускаете из консоли).
   - *Быстрый переход можно открыть прямо из меню приложения: кликните на иконку в статус-баре → «🛡️ Проверить разрешения».*

## Управление через Menu Bar

При запуске в строке меню появляется иконка `🎙️ Giga`.

- **Индикация статуса**:
  - `🎙️ Giga` — Готов к работе.
  - `🔴 Запись...` — Идет запись вашего голоса.
  - `⚡ Обработка...` — Распознавание моделью GigaAM-v3 и вставка под курсор.
- **Пункты меню**:
  - **Модель GigaAM**: переключение между `v3_e2e_ctc` (по умолчанию), `v3_e2e_rnnt`, `v3_ctc`, `v3_rnnt`.
  - **Устройство ускорения**: `Apple Silicon GPU (MPS)` или `CPU`.
  - **Режим вызова клавиши**: `Push-to-Talk` или `Toggle`.
  - **Горячая клавиша**: выбор из популярных клавиш (`Right Shift`, `Right Option`, `F8`, `Ctrl+Space`) или ввод своей клавиши.
  - **Звуковые сигналы**: включение/выключение звуков.
  - **История**: последние 10 транскрипций.

## Конфигурация

Все настройки сохраняются в формате JSON по пути:
`~/.config/giga_dictate/config.json`

Пример конфигурации:
```json
{
  "hotkey": "right_shift",
  "hotkey_mode": "push_to_talk",
  "model_name": "v3_e2e_ctc",
  "device": "mps",
  "sound_feedback": true,
  "restore_clipboard": false,
  "add_trailing_space": true,
  "paste_delay": 0.03,
  "min_duration": 0.25,
  "audio_device": null
}
```

## Автозагрузка при старте Mac

Чтобы GigaDictate запускался автоматически при входе в систему:
1. Откройте **Системные настройки → Основные → Объекты автозагрузки** (System Settings → General → Login Items).
2. В секции «Открывать при входе» нажмите `+` и добавьте `GigaDictate.app`.
